# Internet Programming & Web Development Projects

A consolidated collection of Internet Programming (IP) coursework, frontend labs, and campus web applications.

---

## Projects Overview

### 1. `01-ip-project`
- **Description:** Full-stack Internet Programming project with Backend API and Frontend user interfaces.
- **Features:** Landing pages, structured views, and responsive styling.

### 2. `02-ip-practice`
- **Description:** Core Internet Programming exercises and frontend layout experiments.
- **Features:** HTML5 semantic layouts, modern CSS styling patterns, and client-side interactions.

### 3. `03-haramaya-health-campus`
- **Description:** Complete website for Haramaya Health Campus.
- **Features:** Responsive navigation, campus map integration, interactive JavaScript utilities, and modern CSS layout.
