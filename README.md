## 🌟 Key Highlights & Features

### 1. 🏥 Haramaya Health Campus Website
- **Modern Responsive Design:** Tailored for mobile, tablet, and desktop screens using Flexbox and CSS Grid.
- **Academic Program Directory:** Filterable catalog of medical and health sciences degree programs.
- **Research Hub:** Showcase of clinical publications, staff research, and laboratory initiatives.
- **Campus Facility Map:** Visual navigation assistance for students, staff, and visitors.
- **Downloadable Brochure:** Integrated PDF campus brochure download.

### 2. 🎓 IP Project & Student Registration
- **Sleek Landing Page:** Engaging hero section, call-to-actions, and feature highlights.
- **Student Onboarding:** Multi-field registration form with accessible input validation.
- **Multimedia Integration:** Custom-embedded audio player and video instruction guides.

### 3. 🧪 Hands-on Practice Labs
- **Complex Table Structures:** Advanced HTML tables with rowspan, colspan, and custom zebra striping.
- **CSS Styling Techniques:** Comparative studies of Inline, Internal, and External CSS architectures.
- **Semantic HTML5 Layouts:** Structured header, nav, main, section, aside, and footer elements.

## 🛠️ Local Development & Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/gemachistesfaye/internet-programming-projects.git
   cd internet-programming-projects
   ```

2. **Open the Showcase Hub:**
   Double click `index.html` or run a local server:
   ```bash
   # Using Python 3
   python -m http.server 8000
   ```
   Then visit `http://localhost:8000` in your browser.
